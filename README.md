# Project

A lightweight utility focused on fast, predictable performance.

## Accessibility

This project aims to be usable by everyone. When contributing, please:

- Provide descriptive text alternatives for any non-text content.
- Ensure interactive elements are keyboard-navigable and have visible focus states.
- Maintain sufficient color contrast (WCAG AA or better).
- Prefer semantic markup; use ARIA attributes only when no native equivalent exists.

Reports of accessibility issues are welcome via the issue tracker. Please include steps to reproduce and the assistive technology used, if any.
